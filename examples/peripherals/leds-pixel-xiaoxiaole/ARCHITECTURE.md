## 数据流图

### 输入流 (按钮 → 子弹)

```
硬件按钮
   │
   ▼ (GPIO 中断)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ISR 上下文
   │
   ├─ 按钮中断回调 (ISR)
   │      │
   │      └─→ __btn_cb(SHOT_RED)
   │           ├─ s_pending_shot = SHOT_RED (volatile 赋值)
   │           └─ (快速返回，无阻塞)
   │
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 应用线程
   │
   └─ 主游戏循环
        │
        ├─ 读取 s_pending_shot
        │  └─ if (s_pending_shot != SHOT_NONE) { ... }
        │
        ├─ __create_bullet(shot_type)
        │  ├─ 分配 bullet 对象
        │  ├─ 设置初始位置 (GAME_FIELD_START = 3)
        │  ├─ 设置颜色 (color - 1)
        │  └─ 激活标志 (active = 1)
        │
        ├─ 清除 s_pending_shot = SHOT_NONE
        │  (防止重复触发)
        │
        └─ 子弹在下一帧开始移动
```

### 碰撞流 (子弹 + 块 → 消除/壳弹)

```
子弹在位置 P 移动
   │
   ▼
检测相同位置的色块
   │
   ├─ 找到块 B 在同位置 P
   │  │
   │  ├─ if (子弹.color == 块.color)  ← 面色匹配
   │  │  │
   │  │  ├─ 块.active = 0  (消除)
   │  │  ├─ 子弹.active = 0  (消除)
   │  │  ├─ score += GAME_SCORE_PER_HIT * (combo + 1)
   │  │  ├─ combo++  (连击递增)
   │  │  ├─ 播放命中音效 (可选)
   │  │  └─ 日志输出: "Hit! Score: XXX, Combo: YYY"
   │  │
   │  └─ else  ← 面色不匹配
   │     │
   │     ├─ 块.active = 0  (消除)
   │     ├─ 子弹.active = 0  (消除)
   │     ├─ __create_shell(位置 P)
   │     │  ├─ 生成壳弹对象 (is_shell = 1)
   │     │  ├─ 设置闪烁计时器
   │     │  └─ 激活爆炸效果
   │     ├─ score -= GAME_SCORE_PENALTY (通常为 0)
   │     ├─ combo = 0  (重置连击)
   │     ├─ 播放偏离音效 (可选)
   │     └─ 日志输出: "Mismatch! Creating shell"
   │
   └─ 继续游戏循环
```

### 下落流 (色块 → 火焰区)

```
色块在位置 P (从顶部 149 开始)
   │
   ▼ (每 fall_interval 毫秒)
色块下降: P--
   │
   ├─ if (P > GAME_FIELD_START = 3)
   │  └─ 继续下落，进入下一循环
   │
   └─ else (P < 3，进入火焰区)
      │
      ├─ 块.active = 0  (消除)
      ├─ lives--  (生命值减 1)
      ├─ 日志输出: "Life lost! Remaining: X"
      │
      └─ if (lives == 0)
         └─ game_over = 1  (游戏结束)
```

### 渲染流 (状态 → LED 条)

```
┌─────────────────────────────────────────────────────────┐
│ __render_strip() 每 15ms 调用一次                       │
└──────────────────────┬──────────────────────────────────┘
                       │
                       ▼
         1️⃣ 清屏 - 全黑 (RGB 0,0,0)
            for (i = 0; i < 150; i++)
               tdl_pixel_set_single_color(..., BLACK)
                       │
                       ▼
         2️⃣ 火焰区渲染 (索引 0-2)
            if (碰撞闪烁计时器有效?)
               颜色 = 白色 (255,255,255)
            else
               颜色 = 暗黄 (127,127,0)
                       │
                       ▼
         3️⃣ 色块渲染
            for each (块 ∈ 活跃列表)
               if (块.is_shell)
                  颜色 = 白色 + 闪烁效果
               else
                  颜色 = 块的 RGB
               tdl_pixel_set_single_color(..., 颜色)
                       │
                       ▼
         4️⃣ 子弹渲染 (更亮)
            for each (子弹 ∈ 活跃列表)
               颜色 = 子弹的 RGB (最大亮度)
               tdl_pixel_set_single_color(..., 颜色)
                       │
                       ▼
         5️⃣ 提交刷新
            tdl_pixel_dev_refresh()
                       │
                       ▼
            ✓ LED 条更新完成
            (等待下一个 15ms 周期)
```

## 难度曲线

```
难度 (Level)
   │
   │  ╱╲ ╱╲ ╱╲ ╱╲ ╱╲ ╱╲ ╱╲ ╱╲ ╱╲ ╱
   │ ╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱  ╲╱
  10├────────────────────────────────── Level 10
   │ ╱
   │╱
   1├─────────────────────────────────────
   │
   └─────────────────────────────────────► 分数 (score)
     0      100     200     300     400+

升级条件: score >= GAME_LEVEL_UP_SCORE × (current_level - 1)

示例:
  score  0-99   → Level 1 (生成 800ms, 下落 500ms)
  score 100-199 → Level 2 (生成 700ms, 下落 450ms)
  score 200-299 → Level 3 (生成 600ms, 下落 400ms)
  ...
  score 900+    → Level 10 (生成 200ms, 下落 120ms)
```

## 并发/同步

```
ISR 线程                          应用线程
────────────────────────────────────────────

Button GPIO 中断
   │
   ├─→ __btn_cb(SHOT_RED)
   │
   ├─→ s_pending_shot = SHOT_RED  ←┐ volatile
   │                                │ 原子操作
   └─→ ISR 返回                      │
                                 (ISR 完成)

       (主循环继续)
              │
              ├─ if (s_pending_shot != SHOT_NONE)
              │  └─ __create_bullet()
              │
              ├─ s_pending_shot = SHOT_NONE  ←┐ 清除标志
              │                               │ (防止重复)
              │
              └─ 继续下一帧

关键点:
✓ volatile 确保编译器不优化
✓ 原子操作保证读/写的原子性 (8 位标志)
✓ 无自旋锁或信号量，性能高
✓ ISR 执行时间 < 1μs
```
