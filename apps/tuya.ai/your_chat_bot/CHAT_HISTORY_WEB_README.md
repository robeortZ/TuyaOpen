# 聊天记录网页显示功能

## 功能说明

本功能为 `your_chat_bot` 应用添加了聊天记录存储和网页显示功能，类似于微信聊天记录的展示方式。

### 主要特性

1. **聊天记录存储**：自动保存用户和AI助手的对话记录
2. **Web界面**：通过浏览器访问设备IP地址查看聊天记录
3. **实时更新**：网页每2秒自动刷新，显示最新消息
4. **美观界面**：仿微信风格的聊天界面设计

## 使用方法

### 1. 编译和运行

正常编译和运行应用，聊天记录功能会自动启用。

### 2. 访问Web界面

1. 确保设备已连接到网络
2. 获取设备的IP地址（可通过日志查看）
3. 在浏览器中访问：`http://<设备IP>:8080`

例如：`http://192.168.1.100:8080`

### 3. 查看聊天记录

- 网页会自动显示所有聊天记录
- 用户消息显示在右侧（绿色背景）
- AI助手消息显示在左侧（灰色背景）
- 每条消息都显示时间戳
- 页面每2秒自动刷新，显示最新消息

## API接口

Web服务器提供以下接口：

- `GET /` 或 `GET /index.html` - 返回HTML页面
- `GET /api/chat` - 返回JSON格式的聊天记录

### JSON格式示例

```json
{
  "messages": [
    {
      "timestamp": 1701234567,
      "type": 0,
      "text": "你好"
    },
    {
      "timestamp": 1701234568,
      "type": 1,
      "text": "你好！有什么可以帮助你的吗？"
    }
  ],
  "count": 2
}
```

- `timestamp`: Unix时间戳
- `type`: 0=用户消息, 1=AI助手消息
- `text`: 消息内容

## 配置说明

### 聊天记录配置

在 `app_chat_history.h` 中可以配置：

- `CHAT_HISTORY_MAX_MESSAGES`: 最大消息数量（默认1000条）
- `CHAT_MESSAGE_MAX_LEN`: 单条消息最大长度（默认2048字节）

### Web服务器配置

在 `app_web_server.h` 中可以配置：

- `WEB_SERVER_PORT`: Web服务器端口（默认8080）
- `WEB_SERVER_MAX_CONNECTIONS`: 最大连接数（默认5）

## 技术实现

### 聊天记录存储

- 使用循环缓冲区存储消息，避免内存溢出
- 消息包含时间戳、类型和文本内容
- 支持JSON格式导出

### Web服务器

- 基于TCP Socket实现的简单HTTP服务器
- 支持GET请求和基本路由
- 内嵌HTML/CSS/JavaScript，无需外部文件
- 自动处理CORS，支持跨域访问

### 集成方式

- 在 `app_chat_bot_init()` 中初始化聊天记录模块和Web服务器
- 在 `__app_ai_audio_evt_inform_cb()` 回调中保存消息
- 支持流式和非流式两种AI回复模式

## 注意事项

1. **内存使用**：聊天记录存储在内存中，设备重启后会丢失
2. **网络要求**：需要设备连接到网络才能访问Web界面
3. **性能影响**：Web服务器运行在独立线程中，对主程序影响较小
4. **安全性**：当前实现为简单版本，未包含身份验证，仅适用于内网环境

## 故障排查

### 无法访问Web界面

1. 检查设备IP地址是否正确
2. 确认设备已连接到网络
3. 检查防火墙是否阻止了8080端口
4. 查看日志确认Web服务器是否成功启动

### 聊天记录未显示

1. 确认有进行过对话
2. 检查浏览器控制台是否有错误
3. 直接访问 `/api/chat` 查看JSON数据是否正确
