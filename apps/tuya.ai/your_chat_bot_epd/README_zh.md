# your_chat_bot_epd

[your_chat_bot_epd](https://github.com/tuya/TuyaOpen/tree/master/apps/tuya.ai/your_chat_bot_epd) 是基于 tuya.ai 开源的大模型智能聊天机器人，专为 **墨水屏 (e-Paper/EPD)** 设计。采用 T 形布局设计，包含状态栏、图片区域和时间显示，支持局部刷新以实现高效更新。

## 功能特性

1. **墨水屏显示支持**
   - 7.5 英寸墨水屏 (微雪 EPD_7IN5_V2)
   - T 形布局设计
   - 时间局部刷新（每分钟一次）
   - 背景全屏刷新初始化

2. **T 形布局设计**
   ```
   +--------------------------------------------------+
   |        状态栏（日期 + WiFi 状态）                | 50px
   +--------------------------------------------------+
   |                      |  时间 (HH:MM)             |
   |       图片区域       |---------------------------|
   |       （左侧）       |  天气信息                 |
   |       350x430        |  - 当前温度               |
   |                      |  - 湿度                   |
   |                      |  - 风向风速               |
   |                      |  - 今日高低温             |
   +----------------------+---------------------------+
   ```

3. **天气信息显示**
   - 当前温度和湿度
   - 天气描述（晴、多云、雨等）
   - 风向和风速
   - 今日最高/最低温度
   - 每 30 分钟自动从涂鸦云获取更新

4. AI 智能对话
5. 按键唤醒 / 语音唤醒
6. 蓝牙快速配网

## 硬件依赖

1. 音频采集（麦克风）
2. 音频播放（扬声器）
3. **墨水屏显示器**（推荐 7.5 英寸）
   - 微雪 7.5 寸墨水屏 V2 (800×480)
   - SPI 接口连接

## 引脚配置（T5AI 默认）

| 功能 | GPIO 引脚 |
| --- | --- |
| EPD_RST (复位) | GPIO_26 |
| EPD_DC (数据/命令) | GPIO_24 |
| EPD_CS (片选) | GPIO_16 |
| EPD_BUSY (忙信号) | GPIO_25 |
| SPI_CLK (时钟) | GPIO_14 |
| SPI_MOSI (数据) | GPIO_17 |

## 编译方法

1. 运行 `tos config_choice` 命令，选择当前使用的开发板。
2. 如需修改配置，运行 `tos menuconfig` 命令。
3. 运行 `tos build` 命令，编译工程。

## API 参考

### 显示函数

| 函数 | 说明 |
| --- | --- |
| `EPD_7in5_V2_init()` | 初始化墨水屏并绘制 T 形布局 |
| `EPD_7in5_update_time(time_str)` | 局部刷新更新时间显示 |
| `EPD_7in5_update_status(date_str, wifi)` | 局部刷新更新状态栏 |
| `EPD_7in5_init_layout(date, time, wifi)` | 全屏刷新初始化完整布局 |
| `EPD_7in5_set_weather(...)` | 设置天气数据 |
| `EPD_7in5_update_weather()` | 局部刷新更新天气区域 |

### 天气 API（涂鸦云服务）

| 函数 | 说明 |
| --- | --- |
| `tuya_weather_get_current_conditions()` | 获取当前温度、湿度、天气代码 |
| `tuya_weather_get_current_wind()` | 获取风向和风速 |
| `tuya_weather_get_today_high_low_temp()` | 获取今日最高/最低温度 |

### 刷新策略

- **时间显示**：每分钟局部刷新（速度快、功耗低）
- **状态栏**：日期变化时局部刷新
- **天气显示**：每 30 分钟局部刷新
- **背景**：仅初始化时全屏刷新

## 注意事项

1. 墨水屏有刷新次数限制，应避免频繁全屏刷新。
2. 对于频繁更新的内容，推荐使用局部刷新。
3. 多次局部刷新后可能出现残影，可通过偶尔全屏刷新清除。
4. 墨水屏刷新速度较慢，全屏刷新约需 2-3 秒，局部刷新约 0.3-0.5 秒。

## 显示效果

- **状态栏**：黑底白字，显示日期和 WiFi 连接状态
- **左侧图片区**：显示 Tuya Logo 图案
- **右侧上方**：大字体显示当前时间（HH:MM 格式）
- **右侧下方**：天气信息区
  - 天气描述（Sunny、Cloudy、Rain 等）
  - 当前温度
  - 今日最高/最低温度
  - 湿度百分比
  - 风向和风速

## 天气服务说明

天气数据从涂鸦云获取，需要设备成功连接涂鸦云服务后才能获取。设备首次联网后会自动获取天气数据，之后每 30 分钟自动更新一次。
