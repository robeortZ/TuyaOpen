# BuddyPixel 使用手册

Claude Code 的像素屏伴侣 — 在 32×32 LED 矩阵上实时显示 Claude 的工作状态。

---

## 系统要求

- Windows 10/11、macOS 12+、或 Ubuntu 20.04+
- Python 3.9+
- 蓝牙 4.2+（笔记本内置或 USB 适配器）
- TUYA_T5AI_PIXEL 开发板

---

## 第一步：烧录固件

使用涂鸦烧录工具（tyutool / BKFIL）烧录固件文件：

```
apps/buddy_pixel/dist/buddy_pixel_1.0.0/buddy_pixel_QIO_1.0.0.bin
```

烧录完成后设备自动重启，屏幕显示 **sleeping 动画**（月亮图案），蜂鸣器发出两声启动音表示正常。

---

## 第二步：配置 WiFi（可选）

> 如果只使用蓝牙连接，可以跳过此步骤。

首次烧录后，设备找不到 WiFi 配置会自动进入 **配置模式**：

1. 手机或电脑搜索 WiFi，连接到热点 **`BuddyPixel-Setup`**（无密码）
2. 浏览器访问 **`http://192.168.4.1`**
3. 填写：
   - WiFi 名称和密码
   - 桥接服务器 IP 和端口（如使用 buddy_bridge 则填写，否则留空）
4. 点击「保存并重启」

> **重新配置 WiFi**：长按 OK 键约 3 秒，蜂鸣器响三声后自动清除配置并重启。

---

## 第三步：安装 PC 端脚本

### 安装依赖

```bash
pip install bleak
```

### 首次扫描设备（缓存地址）

确保设备已开机，然后运行：

```bash
python3 /绝对路径/TuyaOpen/tools/buddy_hook/buddy_hook.py scan
```

**Windows 示例：**
```cmd
python C:\TuyaOpen\tools\buddy_hook\buddy_hook.py scan
```

成功输出：
```
正在扫描 BuddyPixel …
找到: BuddyPixel (C8:47:8C:00:00:19)
地址已缓存到 ~/.buddy_pixel_addr
```

> 扫描只需做一次，地址会被缓存。更换设备时运行 `clear` 子命令清除缓存。

### 验证连接

```bash
python3 buddy_hook.py busy
```

设备屏幕切换到 **BUSY 动画**（建筑/打字等随机动画）即表示连接成功。

---

## 第四步：配置 Claude Code Hooks

编辑 `~/.claude/settings.json`，将 `/绝对路径/` 替换为实际路径：

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": ".*",
        "hooks": [
          {
            "type": "command",
            "command": "python3 /绝对路径/TuyaOpen/tools/buddy_hook/buddy_hook.py busy"
          }
        ]
      }
    ],
    "Stop": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "python3 /绝对路径/TuyaOpen/tools/buddy_hook/buddy_hook.py celebrate"
          }
        ]
      }
    ],
    "Notification": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "python3 /绝对路径/TuyaOpen/tools/buddy_hook/buddy_hook.py attention"
          }
        ]
      }
    ]
  }
}
```

**Windows 路径示例：**
```json
"command": "python C:\\TuyaOpen\\tools\\buddy_hook\\buddy_hook.py busy"
```

保存后，**重启 Claude Code** 使 hooks 生效。

## 状态说明

共 6 个状态：

| 屏幕动画 | 状态名 | 触发方式 |
|---------|--------|---------|
| 月亮睡觉 | DISCONNECTED | BLE 断开自动进入 |
| 小人闲逛 | IDLE | BLE 连接后默认；CELEBRATE 8 秒后自动切入 |
| 建筑/打字等 | BUSY | hooks: `busy`（PreToolUse） |
| 感叹号闪烁 + 蜂鸣 | ATTENTION | hooks: `attention`（Notification）或 `approve` |
| 庆祝动画（8 秒） | CELEBRATE | hooks: `celebrate`（Stop），自动超时回 IDLE |
| 眩晕动画（3 秒） | DIZZY | 长按 B 键，自动超时回上一状态 |

---

## 硬件按键

| 按键 | 操作 | 普通状态功能 | ATTENTION 状态功能 |
|------|------|------------|------------------|
| OK（button1） | 单击 | — | **允许一次**：批准当前工具调用 |
| OK（button1） | 长按 3 秒 | 清除 WiFi 配置并重启 | 同左 |
| A（button2） | 单击 | 发送 navigate 事件 | **本次会话不再询问**：批准并记住此工具，本次 daemon 运行期间同类调用自动放行 |
| B（button3） | 单击 | — | **拒绝**：取消当前工具调用 |
| B（button3） | 长按 | 触发眩晕动画 | 同左 |

---

## 可选：设备按键审批工具调用

在 `settings.json` 中将 `PreToolUse` 改为 `approve` 模式，Claude 调用指定工具前，
设备会进入 ATTENTION 状态并显示命令内容，需要按键确认才能继续：

```json
"PreToolUse": [
  {
    "matcher": "Bash|Write|Edit",
    "hooks": [
      {
        "type": "command",
        "command": "python3 /绝对路径/TuyaOpen/tools/buddy_hook/buddy_hook.py approve"
      }
    ]
  }
]
```

- **OK 键**：允许执行
- **B 键**：拒绝（Claude Code 取消本次工具调用）
- **超时 30 秒**：自动拒绝

## 手动测试命令

不需要 Claude Code 也可以直接测试各种状态：

```bash
# 切换到不同状态
python3 buddy_hook.py idle
python3 buddy_hook.py busy
python3 buddy_hook.py celebrate
python3 buddy_hook.py attention

# 扫描并缓存设备地址
python3 buddy_hook.py scan

# 清除缓存（更换设备时使用）
python3 buddy_hook.py clear

# 调试模式（显示 BLE 通信日志）
BUDDY_DEBUG=1 python3 buddy_hook.py busy
```

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| `bleak not installed` | 未安装依赖 | `pip install bleak` |
| `BuddyPixel not found` | 设备未开机或不在附近 | 确认设备开机，重新运行 `scan` |
| 扫描成功但发送失败 | 缓存地址过期（换了设备） | `python3 buddy_hook.py clear` 后重新 `scan` |
| hooks 不触发 | settings.json 路径有误 | 检查路径是否为绝对路径，Windows 用双反斜杠 |
| hooks 触发但设备无反应 | BLE 连接慢（首次需扫描） | 先手动运行 `scan` 缓存地址 |
| Linux 下权限错误 | BlueZ 蓝牙权限 | `sudo python3 buddy_hook.py scan` 或授权 Python 蓝牙权限 |
| 设备重启进入配置模式 | 误触长按 OK | 连接 `BuddyPixel-Setup` 热点重新配置 WiFi |
